# Narrative structures

## 1. Problem → Solution → Features → CTA (explainer, style A)
The workhorse for products and services. 25–35s.

| Beat | Time | What happens |
|---|---|---|
| Open | 0–2s | Logo on clean background with decorative rings, or a lively scene that sets the place (café, restaurant, office) |
| Empathy line | 2–5s | A short caring line in a decorative frame ("ولأنك غالي علينا…") |
| Problem | 5–9s | Character with a "؟" mark; pill labels list the pains next to a clock or warning icon |
| Reveal | 9–11s | Transition (iris, push or panel wipe) into the product: logo or device mockup |
| Steps / features | 11–22s | Hand + phone showing the flow; numbered pills accumulate 1 → 2 → 3 → 4, one every ~1s, the UI on the phone changes with each pill |
| Proof | 22–24s | Background blurs; a badge pops ("✓ الأمور سهلة"), sparkles |
| Outcome | 24–26s | Real-life result scene (customer picks up the order from the car, happy client) |
| End card | 26–32s | Logo → tagline pill → website/handle rows → QR, staggered, then hold 3–7s |

## 2. Hook question → tension → answer → push (kinetic, style B)
For reels that must stop the scroll. 15–35s.

| Beat | Time | What happens |
|---|---|---|
| Hook | 0–2s | A direct question in dialect, word-by-word, camera already moving |
| Tension | 2–8s | Contrast imagery: the one who stands out vs the crowd, confusion, pressure; keyword in accent color |
| Turn | 8–12s | "بس…" / "والسبب…": reveal the reason; big accent word |
| Value | 12–25s | 2–4 short proof points, each with its own cutout image; a humor sticker once |
| Push | last 3–5s | CTA question or command ("يلا شمنتظر؟"), handle |

## 3. Build-up → reveal → statement (occasion, style C)
8–12s.

| Beat | Time | What happens |
|---|---|---|
| Build | 0–3s | Pattern detail fills the frame; title assembles from pattern blocks |
| Reveal | 3–6s | Camera pulls back to the full scene (portrait, majlis, landmark) |
| Statement | 6–9s | Color overlay settles; large slogan with stretched letters |
| Sign-off | 9–12s | Small logo fades in under the slogan, hold |

## 4. Logo reveal
3–5s: background detail (rings, lines or pattern) draws in 0–1s → logo mark scales/morphs in 1–2s → wordmark + tagline slide in 2–3s → hold.

## Script rules
- One message per video; one sentence per scene.
- Write in the audience's dialect or in simple MSA — not a mix.
- Keep each on-screen line ≤ 6 words. Long lines become two scenes.
- Use numbers for steps (١ ٢ ٣ or 1 2 3, consistently).
